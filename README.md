# GM Studio

**GM Studio** is an open-source desktop workspace designed to help tabletop RPG Game Masters prepare, organize, and run immersive campaigns.

## Vision

GM Studio aims to bring campaign notes, scripts, character sheets, reference documents, visual planning, image collections, and audio controls into one customizable workspace.

The goal is to provide a flexible, reliable, and accessible tool for Game Masters, with local-first data storage and optional Discord integration.

## Planned Features

- Campaign and project management
- Customizable workspace with panels and layouts
- Notes, scripts, and character sheets
- PDF viewing and external reference links
- Visual mind map with drawings, cards, connections, and images
- Image library with tags and categories
- Audio library, soundboard, and independent volume controls
- Optional Discord integration for voice audio and image sharing
- Autosave, backups, and campaign data isolation
- Multilingual interface

## Project Status

**Early development — planning and initial setup.**

Features listed above are planned and may change as development progresses.

## Technology

The initial technology stack is planned to include:

- Electron
- React
- TypeScript
- Vite
- Python for selected background services
- SQLite for structured local data

The final choices will be validated during development.
