# Contributing to GM Studio

Thank you for your interest in contributing to GM Studio!

GM Studio is an open-source desktop application designed to help tabletop RPG game masters organize campaigns, manage references, create mind maps, and coordinate audio and media during sessions.

## Current Project Status

GM Studio is in early development. Features, architecture, and development guidelines may change as the project evolves.

Before implementing a major feature or making a significant architectural change, please open an issue to discuss the proposal.

## How to Contribute

1. Check the existing issues to see whether the problem or feature has already been discussed.
2. Open an issue describing the bug, improvement, or proposed feature.
3. Wait for feedback before starting major changes.
4. Create a branch for your work.
5. Make focused changes that are easy to review.
6. Test your changes and update the documentation when necessary.
7. Submit a pull request explaining what changed and why.

## Development Guidelines

- Keep the code readable and maintainable.
- Prefer small, focused changes.
- Follow the existing project structure and conventions.
- Avoid adding unnecessary dependencies.
- Keep user data and credentials secure.
- Never commit passwords, Discord bot tokens, API keys, or other secrets.
- Update tests and documentation when appropriate.
- Consider Windows and Linux compatibility.

## Bug Reports and Feature Requests

When opening an issue, provide as much relevant information as possible.

For bug reports, include:
- A clear description of the problem.
- Steps to reproduce it.
- Expected and actual behavior.
- Operating system and relevant application details.

For feature requests, explain the problem the feature would solve and how it would improve the GM Studio experience.

## Code of Conduct

Be respectful, constructive, and welcoming. Harassment, discrimination, and personal attacks are not acceptable.
